# Proyecto Dosificadora

## Descripción

Sistema de dosificación automatizada que utiliza una ESP32-S3 para controlar y supervisar el funcionamiento de una máquina dosificadora.

El proyecto contempla la detección de producto en una tolva, el accionamiento de motores y un pistón eléctrico, así como una interfaz de usuario para visualizar información y controlar el proceso.

## Componentes

- Microcontrolador ESP32-S3.
- Pantalla LCD.
- Sensores capacitivos.
- Motor paso a paso.
- Pistón eléctrico.
- Sensor de vibración.
- Paro de emergencia.

## Funcionamiento

El sistema cuenta con una interfaz de bienvenida y un menú principal desde el cual se podrá controlar la máquina.

También incluye un submenú para consultar información de los sensores y supervisar el proceso de dosificación.

## Estructura del proyecto

- `src/python/simulador_menu.py`: Simulador de la interfaz de usuario desarrollado en Python.
- `src/firmware/Pantalla_LCD/Pantalla_LCD.ino`: Programación de la pantalla LCD para la ESP32-S3.
- `src/firmware/Pantalla_LCD/Pantalla_LCD_v1_estable.txt`: Respaldo de una versión estable.
- `src/firmware/Pantalla_LCD/Pantalla_LCD_respaldo.txt`: Respaldo del firmware.

## Tecnologías utilizadas

- Python.
- C/C++ para Arduino.
- Arduino IDE.
- Visual Studio Code.
- Git y GitHub.
